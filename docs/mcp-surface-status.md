# Surface-status table for spec 2026-07-28 (triage reference)

Publishing the reviewed surface-status table this issue asks for. One precision matters before the table: in revision 2026-07-28 the named method removals come from [SEP-2575](https://modelcontextprotocol.io/seps/2575) ("Make MCP Stateless"), while [SEP-2577](https://modelcontextprotocol.io/seps/2577) ("Deprecate Roots, Sampling, and Logging") puts Roots/Sampling/Logging into **Deprecated** with a minimum twelve-month window ([SEP-2596](https://modelcontextprotocol.io/seps/2596)), and [SEP-2322](https://modelcontextprotocol.io/seps/2322) replaces the standalone server-to-client request forms (`roots/list`, `sampling/createMessage`, `elicitation/create`) with the MRTR pattern. So the panes this issue groups together actually split into three buckets: removed, deprecated with a sunset, and reshaped but alive.
