Local patches against upstream
==============================

One file per patch in NOTICE.d/, named after what the patch does.
Add a patch by adding a file there. Nothing lists them: `ls NOTICE.d/`
is the index, so two patches landing at once never touch the same line.

The registry used to live here as a numbered list. Every parallel patch
collided on it, and resolving that collision renumbered entries that
code comments referenced by number. Reference a patch from code by its
file name, never by a number, and never add an index back to this file.
