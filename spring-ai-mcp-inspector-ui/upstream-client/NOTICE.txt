Local patches against upstream
==============================

One file per patch in NOTICE.d/, named after what the patch does.
Add a patch by adding a file there. Nothing lists them: `ls NOTICE.d/`
is the index, so two patches landing at once never touch the same line.

The registry used to be a numbered list; avoid re-introducing numbers.
Reference a patch from code by its file name, never by a number.
