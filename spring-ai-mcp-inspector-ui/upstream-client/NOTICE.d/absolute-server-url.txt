— resolve a relative same-origin server URL against the current origin
before handing it to `new URL(...)` as a base (`toAbsoluteServerUrl`).
Patch 5 makes the default target the relative `/mcp`, and
`new URL("/", "/mcp")` throws `Invalid URL`, which aborted OAuth
discovery on the default configuration. The same applies wherever the
value reaches the SDK: `auth()` and the state machine both funnel it
into `resourceUrlFromServerUrl` -> `new URL(serverUrl)`.
The proxy path keeps the relative value, so the WAF-safety of patch 5
is unaffected.
