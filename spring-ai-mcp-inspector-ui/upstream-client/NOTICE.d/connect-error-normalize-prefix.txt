src/lib/hooks/useConnection.ts - normalize the "Connection error" toast
message to remove the duplicated "Error:" prefix. `${e}` in a template
literal calls Error.prototype.toString() which prepends "Error: " to
the message, and the SDK's own error classes already carry their own
"Error:" prefix. The fix uses connectionFailureFromError(e).message
instead, which strips the duplicate prefix. Covered by the existing
useConnection.test.tsx scenarios.
