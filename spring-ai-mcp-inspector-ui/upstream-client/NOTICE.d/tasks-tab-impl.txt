spring-ai-mcp-inspector-ui/upstream-client:
src/App.tsx: wire up getTask() callback for per-task polling and
pass it to TasksTab. Mount stays gated on
serverCapabilities?.tasks so the component and its polls are
never rendered against servers that do not advertise MCP Tasks
support (regression-tested at the App level: a mutated
unconditional mount is caught by the gate tests in
src/__tests__/App.tasksTabTooltip.test.tsx).
src/components/TasksTab.tsx: auto-polling, per-task polling, TTL
countdown, status animations, empty state. The list poll reads
the callback through a ref at call time and is keyed only on
activeTab: App passes an inline arrow, so listTasks has a new
identity on every App render, and keying the effect on the
callback would tear the timer down before it fires. Both polls
use recursive timeouts with exponential backoff (capped at 30s)
while failing and reset on success. Per-task pollers are keyed
on the active task ID string; effect teardown is unmount-only
(a cleanup in the keyed effect would restart surviving tasks'
timers from zero whenever the active set changes). TTL countdown
is measured from lastUpdatedAt (the backend expires
tasks from that timestamp, so keep-alives move the countdown)
and renders "Invalid date" instead of NaN for unparsable
timestamps. An active task whose TTL has elapsed shows "Past
TTL", not "Expired": the backend never evicts working tasks,
"Expired" is reserved for terminal tasks that the sweeper
removes. Both pollers (list and per-task) are gated on
activeTab === "tasks": leaving the tab stops every poller,
returning restarts them. A polled tasks/get result is propagated
into the tasks list through the updateTask callback, not only
into the selected task. TERMINAL_STATUSES follows the SDK
TaskStatus enum exactly ("completed", "failed", "cancelled");
the backend emits "completed" and never "success". Covered by 27
behavior tests in src/components/__tests__/TasksTab.test.tsx
(fake timers for list poll, per-task poll, per-task poll gating,
terminal-state stop, identity-churn regression,
poller-survival regression, backoff, TTL formatting, cancel)
plus 2 App-level capability-gate tests in
src/__tests__/App.tasksTabTooltip.test.tsx.
