inputRequests emitted by onInputRequired with per-type controls (string input,

ORIGINAL tools/call through resendToolCall with the requestState echoed
byte-exact, Cancel abandons the chain. Timeline correlation: new lib/
timelineChains.ts threads the server-recorded request/response pairs into one

awaiting-input / final-result / error state) plus an "input required" badge on
standalone frames. Multi-round chains stay on one correlation id; the final
result lands on the tools tab, so there is no dead-end truncated result.
