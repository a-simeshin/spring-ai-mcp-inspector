  prefilledToolCall.result is now optional (absent = preselect-without-run

  and switch activeTab to "apps"; extended PrefilledAppsToolCall type to

- src/components/__tests__/ui-resource-detection.test.ts: unit tests for
  hasUIMetadata (nested key, deprecated flat key, absent meta, empty
  string, non-ui:// value returns false, null, number, object).
- src/components/__tests__/AppsTab.test.tsx: regression test for malformed
  resourceUri filtered without console error; preselect-without-run test
  (no auto-open); regression test for closing the renderer when a
  result-less preselection arrives while an app is open; PATCH marker header.
- src/components/__tests__/ToolsTab.test.tsx: tests for the "Open as App"
  button visibility and click behavior.

Reason: SEP-1865 detection is tool-metadata-driven (_meta.ui.resourceUri),
not content-sniffing. The button closes the loop between Tools tab and Apps
tab: the user can open an App for a tool directly from Tools without
running it first. The shared guard makes the detection boundary total and
non-throwing for untrusted tool metadata, with a bounded diagnostic.

Covered by: unit tests in ui-resource-detection.test.ts, AppsTab.test.tsx,
and ToolsTab.test.tsx.
