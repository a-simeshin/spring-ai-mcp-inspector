[spring-ai-mcp-inspector PATCH] $ref schema warnings (Spring AI #5888 detector)

File: src/utils/schemaUtils.ts
- Added findUnresolvedRefs() - scans a JSON Schema tree for $ref pointers
  that cannot be resolved within the schema document (broken/recursive refs).
- Added findToolSchemaWarnings() - convenience that checks both inputSchema
  and outputSchema of a Tool.
- Both functions are read-only (no mutation of the stored schema).
- collectUnresolvedRefs traverses all standard schema-bearing locations:
  properties, items, anyOf, oneOf, allOf, $defs, definitions, dependencies,
  not, if/then/else, contains, prefixItems, additionalProperties,
  additionalItems, propertyNames, dependentSchemas, patternProperties,
  contentSchema, unevaluatedProperties, unevaluatedItems
  (no mutation of stored schema).
- decodePointerToken applies RFC 6901 percent-decoding (~1 -> /, ~0 -> ~,
  then URI percent-decoding).
- canResolveRef excludes external URIs and plain-name ($anchor) refs from
  the spring-ai#5888 detector (they are not local JSON Pointers).
- resolveRef uses the same hasOwnProperty + RFC 6901 decoded segment lookup
  as the detector (consistency fix).

File: src/components/ToolsTab.tsx
- Computes per-tool warnings via useMemo when the tools list changes.
- Renders an amber AlertTriangle badge next to each tool with unresolved $ref
  in the list pane.
- Renders a detailed warning Alert in the detail pane when a tool with
  unresolved refs is selected, listing each broken pointer path and linking
  to https://github.com/spring-projects/spring-ai/issues/5888.
