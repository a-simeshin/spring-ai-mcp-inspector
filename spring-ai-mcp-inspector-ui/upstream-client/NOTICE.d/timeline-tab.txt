TimelineTab.tsx, App.tsx, __tests__/TimelineTab.test.tsx — new TimelineTab component that polls /mcp-inspector/api/timeline
and renders a color-coded, expandable chronological event log for MCP traffic and
application logs. No upstream equivalent exists; this is a Spring AI MCP Inspector
extension. Tab icon: Bell (lucide-react, already a project dependency).

severity-colored badge plus an expanded detail block with summary, affectedMethods,

Updated: Replay button for tools/call request rows (PR #223). Clicking Replay emits
onReplay(toolName, args) which switches to the Tools tab, selects the tool (if
still available), and deep-copies the recorded request params into the arguments
form. Missing-tool case degrades gracefully with a visible warning in the Tools tab.

request has a matching response with isError=true, an additional "Replay & diff"
button re-sends the call immediately via callTool and opens a modal with a
side-by-side structural JSON diff (jsonDiff.ts) between the recorded response and
the new response. Identical errors are detected and reported explicitly instead of
showing an empty diff. New files: ReplayDiffModal.tsx, utils/jsonDiff.ts,
__tests__/ReplayDiffModal.test.tsx, __tests__/jsonDiff.test.ts.
