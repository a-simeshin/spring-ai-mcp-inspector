TimelineTab.tsx, App.tsx, __tests__/TimelineTab.test.tsx — new TimelineTab component that polls /mcp-inspector/api/timeline
and renders a color-coded, expandable chronological event log for MCP traffic and
application logs. No upstream equivalent exists; this is a Spring AI MCP Inspector
extension. Tab icon: Bell (lucide-react, already a project dependency).
Updated: protocol-version negotiation badge on initialize response rows (#129, #130).
Reads _protocolNegotiation enrichment from McpTrafficRecorder and renders a
severity-colored badge plus an expanded detail block with summary, affectedMethods,
and a footer link to issue #129. OK severity is silent-positive (badge only, no
expanded block). Badge text and colors follow the decision record (t_9315a78c).
Updated: Replay button for tools/call request rows (PR #223). Clicking Replay emits
onReplay(toolName, args) which switches to the Tools tab, selects the tool (if
still available), and deep-copies the recorded request params into the arguments
form. Missing-tool case degrades gracefully with a visible warning in the Tools tab.
Updated: Copy as JSON-RPC / Copy as curl row actions (PR #224). Every
MCP_JSONRPC_REQUEST row gains two clipboard buttons: (a) copies the raw request
envelope as pretty-printed JSON with a stable id=1 placeholder, (b) copies a
ready-to-run curl targeting the active proxy endpoint <proxy>/mcp with the
X-MCP-Proxy-Auth header and a <TOKEN> placeholder. Clipboard writes use
navigator.clipboard with a textarea+execCommand fallback for non-secure
contexts; failures surface as an error toast, not silently.
