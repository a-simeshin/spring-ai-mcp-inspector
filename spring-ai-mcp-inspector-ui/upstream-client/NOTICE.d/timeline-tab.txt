TimelineTab.tsx, App.tsx, __tests__/TimelineTab.test.tsx — new TimelineTab component that polls /mcp-inspector/api/timeline
and renders a color-coded, expandable chronological event log for MCP traffic and
application logs. No upstream equivalent exists; this is a Spring AI MCP Inspector
extension. Tab icon: Bell (lucide-react, already a project dependency).

severity-colored badge plus an expanded detail block with summary, affectedMethods,
and a footer link to issue #129. OK severity is silent-positive (badge only, no
expanded block). Badge text and colors follow the decision record (t_9315a78c).
Updated: CallToolResult error highlighting (#184). Detects MCP_JSONRPC_RESPONSE
frames whose result.isError is true and renders the row in red (text-red-400 /
border-l-red-500 / bg-red-950/30) with a "validation failed" badge. The badge
tooltip surfaces the first text content block from the result payload so the
developer sees the server-side validation message the LLM received. Successful
rows (isError=false or absent) render unchanged.
