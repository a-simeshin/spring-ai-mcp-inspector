src/lib/leakAnnotations.ts, src/lib/__tests__/leakAnnotations.test.ts - new
shared module for the exception-leak feature (#251). No upstream equivalent;
this is a Spring AI MCP Inspector extension. Contains: defensive parsing of the
`_leak` timeline enrichment (D5 wire shape produced by the server-side
ExceptionLeakDetector; malformed input yields null), the client-side join of an
error CallToolResult with its annotated timeline response event (whitespace
normalized, newest-first), a fetch helper for the timeline page (same endpoint,
auth header and bootstrap-advertised prefix as TimelineTab), the useLeakForToolResult
hook (retries on the Timeline poll cadence because the log appender flush lags),
a cross-tab scroll broker (Tool Results pane -> Timeline tab) that holds one
pending jump while the Timeline is not mounted, and display helpers (200-char
cap, server-side clock extraction). Used by TimelineTab.tsx and ToolResults.tsx.
