Pure TypeScript module in lib/concurrency/ implementing the execution model and data contract from docs/concurrency-probe.md. Runs N parallel tools/call with per-call timeout and abort, sequential iterations, per-call metrics (latency, status, bodyHash via SHA-256 of canonical JSON), aggregates (percentiles, body equality, failure groups), and cancellation with partial result. No new dependencies; SHA-256 uses Web Crypto / node:crypto. Unit tests cover validation limits, percentile edge cases (N=1, all-failed), body equality, cancellation, timeout, and progress callbacks.
