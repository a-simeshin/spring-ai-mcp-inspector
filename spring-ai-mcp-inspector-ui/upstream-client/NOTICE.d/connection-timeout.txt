Description:
  Adds an optional numeric input for connection timeout in seconds.
  Empty = proxy default (30s). Filled = forwarded as connectionTimeout
  query parameter to the proxy. Proxy connections only (the field is
  hidden for direct connections, which never build a proxy URL).
  Validation: whole seconds 1..600 (matching ProxyConnectionBudgets),
  enforced on blur and on the Connect click guard.
  Value persisted to localStorage (lastConnectionTimeout).
